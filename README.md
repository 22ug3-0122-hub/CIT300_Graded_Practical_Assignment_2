# CIT300 Data Structure and Graph Performance Analyzer

Java console application for CIT300 Graded Practical Assignment 2.

## Features
- Array: insert, delete, search, display
- Stack: push, pop, peek, display, empty/full handling
- Queue: enqueue, dequeue, front, display, empty/full handling
- Linked List: insert, delete, search, display
- Searching: Linear Search and Binary Search with steps and execution time
- Graph: adjacency-list representation, vertex/edge operations, BFS and DFS
- Performance comparison and complexity explanation
- Input validation and integrated console menus

## Run
    Open a terminal in `src` and run:

    ```text
    javac *.java
    java Main
    ```

## Project files
`Main.java`, `IntArray.java`, `IntStack.java`, `IntQueue.java`, `IntLinkedList.java`, `SearchManager.java`, `SearchResult.java`, `SearchComparison.java`, `Graph.java`, `TraversalResult.java`, `PerformanceRecord.java`, `PerformanceManager.java`.

## Complexity notes
    Linear Search: O(n)
    Binary Search: O(log n), after data is sorted
    BFS: O(V + E)
    DFS: O(V + E)
    Array insertion/deletion: O(n) in the general case
    Stack push/pop: O(1)
    Queue enqueue/dequeue: O(1)
    Linked-list search: O(n)
